# PicanteríaYa: laboratorio 10

Trabaja únicamente sobre una copia aislada o una rama de trabajo. Nunca fusiones tu propio PR.
Lee el issue antes de editar. Reproduce el fallo, corrige la causa mínima y ejecuta regresiones.
No edites tests para volverlos verdes. No leas credenciales ni ejecutes comandos de red.
Para ISSUE-03, comprueba que un repartidor ocupado no cambia el estado del pedido.
Usa Decimal para dinero. Las cantidades deben ser enteros positivos (bool no cuenta).
Solicita aprobación humana para cada edición; registra rechazos y no los eludas.
Pruebas: python -m pytest -q tests agentes/pruebas_agente
Registra herramientas, resultados, cambios y limitaciones sin inventar evidencia.
